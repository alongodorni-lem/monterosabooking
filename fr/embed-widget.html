Réservations sur votre site

Si vous gérez un blog, un site d’hébergement, un portail ou similaire, vous pouvez offrir à vos clients la possibilité de réserver des expériences directement depuis votre site. Deux modes :

  1. un lien direct à utiliser immédiatement ;
  2. intégrer les expériences sur votre site via un code HTML à coller (dans ce cas, après avoir généré le code sur cette page, vous devez écrire à macugnagabooking@gmail.com pour autoriser la publication sur votre site web).

Méthode 1 — Lien direct

Saisissez votre site internet et générez un lien personnalisé à partager ou à placer sur votre site.

Méthode 2 — Code HTML

Générez le code HTML à coller dans la page de votre site. Après la génération, écrivez à macugnagabooking@gmail.com pour autoriser la publication sur votre site web.

Code de référence :

Copiez le code HTML et collez-le dans la page de votre site. N’oubliez pas d’écrire à macugnagabooking@gmail.com pour autoriser la publication.

Le service est sûr et gratuit ; la provenance des réservations (ex. depuis www.votresite.fr) est enregistrée à des fins statistiques et pour d’éventuelles collaborations futures que vous pourriez engager avec nous.
